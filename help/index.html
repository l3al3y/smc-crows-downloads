IMPORTANT ANNOUNCEMENT

Game frozen? Close and reopen.

Close SMC completely and open it again. You can return to the same match if it is still in progress and your character has not been eliminated.

Reopening is a recovery step. Full-match stability on every device has not been established.

RESOURCE NOTICE / COMMUNITY HELP

Playable, but still not perfect.

Some skins, battle-pass artwork and other content may not appear because the available resource set is incomplete.

I’m the APK merger, not the creator of the game’s resources. If you have a complete SMC resource set, please contact me at cabalme4@gmail.com.

ACCOUNTS & BACKUPS

Keep your recovery information.

r4 preserves an existing account during ordinary setup and repair. Its account files and internal backup are inside the game’s app-specific storage; do not rely on them surviving uninstall or a complete data wipe.

The original PC Crows kit can reuse the same account using account.json kept in its PC kit folder. Keep that file private and backed up if you used that kit. The current Android APK does not provide the equivalent external export/import feature.

If you lose the PC kit folder or change phones, the official Crows Android guide describes contacting Crows for manual account transfer. This is separate from this APK merge.

INSTALLATION & RESOURCES

Use a matching set.

Import all three ZIPs from the Downloads page or let setup download them. Do not mix resource versions. Keep setup open for verification and check storage space.

A community APK update needs the same signing certificate. The original NetEase-signed APK has a different certificate. Avoid clearing or uninstalling an existing game without securing account recovery information first.
