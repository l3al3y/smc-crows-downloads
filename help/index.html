ACCOUNTS & BACKUPS

Keep your recovery information.

r4 preserves an existing account during ordinary setup and repair. Its account files and internal backup are inside the game’s app-specific storage; do not rely on them surviving uninstall or a complete data wipe.

The original PC Crows kit can reuse the same account using account.json kept in its PC kit folder. Keep that file private and backed up if you used that kit. The current Android APK does not provide the equivalent external export/import feature.

If you lose the PC kit folder or change phones, the official Crows Android guide describes contacting Crows for manual account transfer. This is separate from this APK merge.
