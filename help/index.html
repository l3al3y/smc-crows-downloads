v1.0 help

Keep a private exported account backup. App-owned files can disappear after uninstall or a full wipe. Use Change account / import backup before applying Crows when recovering your identity.

For an unavailable online update check, you can still tap Play on a verified installation. Use Check for resource updates to retry later. Updates require a valid signature and matching resource base.

Use Verify and repair resources for changed or missing files. Setup supports retry, pause/resume and offline ZIP import. Do not mix older r4 resources with v1.0.

If an installer reports a conflicting signing certificate, preserve your account backup before any manual replacement. Do not clear game data merely to troubleshoot a download.

Playable, still improving.

Some skins and preview controls remain incomplete. MiloSuam merges available resources and does not create missing original assets. If you have full compatible resources, contact cabalme4@gmail.com.

If a match freezes, close and reopen the game. You may rejoin if your character is still alive; this is not a guarantee for every freeze.
