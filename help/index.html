The game freezes during a match.

Close and reopen the game. You may return to the match if your character is still alive; this is a recovery suggestion, not a guaranteed fix.

A skin or artwork is missing.

The available resources are incomplete. Some pilot/mecha skins and Lucky Draw/Chromatic Ball preview controls remain unresolved. MiloSuam merges files and does not create missing original assets. If you have complete compatible resources, contact cabalme4@gmail.com.

Android refuses to install the APK.

Confirm that the complete download matches its listed size/checksum, allow installation from your chosen browser/file manager and check storage. An existing app with another signing certificate, unsupported CPU/Android version or OS security rule can also cause rejection. Back up your account before any uninstall; support on every Android phone is not established.
