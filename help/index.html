v1.0 help

Keep a private exported account backup. App-owned files can disappear after uninstall or a full wipe. Use Change account / import backup before applying Crows when recovering your identity.

For an unavailable online update check, you can still tap Play on a verified installation. Use Check for resource updates to retry later. Updates require a valid signature and matching resource base.

Use Verify and repair resources for changed or missing files. Setup supports retry, pause/resume and offline ZIP import. Do not mix older r4 resources with v1.0.

If an installer reports a conflicting signing certificate, preserve your account backup before any manual replacement. Do not clear game data merely to troubleshoot a download.

Playable, still improving.

Some skins and preview controls remain incomplete. MiloSuam merges available resources and does not create missing original assets. If you have full compatible resources, contact cabalme4@gmail.com.

If a match freezes, close and reopen the game. You may rejoin if your character is still alive; this is not a guarantee for every freeze.

ACCOUNTS & BACKUPS

Keep your recovery information.

r4 preserves an existing account during ordinary setup and repair. Its account files and internal backup are inside the game’s app-specific storage; do not rely on them surviving uninstall or a complete data wipe.

The original PC Crows kit can reuse the same account using account.json kept in its PC kit folder. Keep that file private and backed up if you used that kit. The current Android APK does not provide the equivalent external export/import feature.

If you lose the PC kit folder or change phones, the official Crows Android guide describes contacting Crows for manual account transfer. This is separate from this APK merge.

INSTALLATION & RESOURCES

Use a matching set.

Import all three ZIPs from the Downloads page or let setup download them. Do not mix resource versions. Keep setup open for verification and check storage space.

A community APK update needs the same signing certificate. The original NetEase-signed APK has a different certificate. Avoid clearing or uninstalling an existing game without securing account recovery information first.
