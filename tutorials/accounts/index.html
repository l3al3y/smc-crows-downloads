Save and recover your account.

Use the latest Setup’s backup and import buttons.

Back up before switching.

  1. Tap Back up my account in the latest Setup.
  2. Save the JSON privately in Documents or another folder outside app-owned storage.
  3. To recover or change accounts, tap Import account backup and choose the saved file.
  4. Review Use this account, confirm, wait for readiness and tap Play.

Treat the backup like a password. Do not post it in Discord or send it publicly. Uninstalling or clearing app data can erase app-owned copies; recovery needs a surviving backup and a working server.
