“I want all players to be able to play this nostalgic game again.”

Matching resources: release `smc-android-20261008-r2`, all three ZIPs required.

This repository contains distribution files and the download website. Setup Java source, tests, build scripts and preservation archives are maintained separately in a private source repository. Signing keys, accounts and raw diagnostics are excluded.

The published APK reached gameplay on Samsung S26 Ultra / Android 16. A persistent dash freeze is reproduced and under investigation. A separate setup reopen candidate is being tested privately; it is not the public APK and is not a proven gameplay freeze fix.

The already-installed r2 APK still uses compatibility resource URLs in the Portfolio release. Those resource assets remain temporarily available so existing installs keep working. New releases need a tested URL migration before that compatibility location can be retired.
