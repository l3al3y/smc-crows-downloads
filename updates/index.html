LATEST UPDATE / 14 OCTOBER 2026

v2.0 · Stable Version

Native game, resource packs and cumulative battle-pass v3 artwork are retained.

Android 16 compatibility update

Version2080310 targets API36, requires Android10/API29 and ARM64, and keeps the same package and signing certificate. Setup handles modern screen insets, Back navigation and its foreground-service timeout. API36 page-size compatibility is requested where supported.

The original native graphics engine and threading code are unchanged. 29 native libraries remain below16KB alignment; this is not native16KB support or a universal installation fix. V1/V2/V3 signatures are retained; an external V4 sidecar was verified for supporting incremental installers. Ordinary users install the APK.

Testing: archive, signing, retained-payload and Setup host checks passed. Earlier2080308 was reported working on Samsung S26 Ultra; exact2080310 phone gameplay is still unverified. Default Firefox freezing, some skins and preview buttons remain unresolved.

  • Play is the main action. Your valid account stays selected; importing a backup is optional.
  • Checks do not block Play. Check for updates is below Play and stays retryable after network failure.
  • Riko welcomes you. Smaller, clearer Setup panels, seated character, synthetic greeting and guarded touch replay.
  • Offline notices. Privacy, community terms and copyright/contact are in Setup.

How future updates work

Compatible signed resource and supported layout/background patches can then use Check for updates and Install resource update. Check only finds a patch; Install applies it. New engine or Setup code still requires an APK upgrade. The current channel reports the retained v3 resources as current; no new donor resource set is being released here.
