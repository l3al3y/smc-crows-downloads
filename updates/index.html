Major Update v1.0

  • 114 cumulative battle-pass artwork replacements.
  • 30 limited pilot texture aliases; this does not fix every reported missing skin.
  • Setup stays open, with manual Play and account export/import.
  • Automatic background check for signed compatible resource updates; installation remains your choice.
  • Matching extensions download automatically when missing, with integrity checks, resume and offline import.

The engine, scripts and base packs retain the working r8 payloads. Other missing skins and Lucky Draw/Chromatic Ball preview buttons remain unresolved. Graphics API research is deferred.

Future compatible resources still need a signed published update. Once available, v1.0 setup can offer it without downloading the entire APK again. Setup/engine/APK changes require an APK update.

Playable, still improving.

Some skins and preview controls remain incomplete. MiloSuam merges available resources and does not create missing original assets. If you have full compatible resources, contact cabalme4@gmail.com.

If a match freezes, close and reopen the game. You may rejoin if your character is still alive; this is not a guarantee for every freeze.

A future setup version is planned to discover and apply matching resource updates. A one-time APK upgrade will be needed to enable this feature. The current r4 APK uses fixed resource identities and does not discover new packs automatically.
