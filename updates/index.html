v1.0 / RELEASE PREPARATION

What changes

Publication preparation: 10 October, 11:35 PM. Five-hour countdown: 11 October, 2:00–7:00 AM. Public downloads: 11 October, 7:00 AM, subject to completed file verification.

Battle-pass UI restored

114 missing images restored across introduction, pass options, Reward and Redeem screens, including reward panels and buttons.

Improved setup

Base resource packs load directly from the APK. Matching installed extensions are reused, and ordinary unchanged reopening uses saved verification rather than repeating a full scan.

Account backup

Setup supports account export and import. Keep an exported backup outside the game's app storage before uninstalling or clearing data.

Verified resource updates

Setup supports importing matching signed resource updates. Online release-channel availability will be documented with the published bundle.

What this update establishes

Battle-pass visual repairs were checked on Samsung S26 Ultra / Android 16, and the player reports the current combination is running well. This is not a universal performance guarantee. The Season over label and server-controlled progression are separate from artwork repairs; purchases and reward claims have not been validated.

Other missing skins or resources can remain. MiloSuam merges available resources; he does not create the original game assets. If you have a complete resource set, contact cabalme4@gmail.com.
