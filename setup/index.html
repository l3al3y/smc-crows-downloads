SETUP GUIDE

Install. Restore. Connect.

Follow the order below. Setup handles the resource paths and integrity checks.

01

Install and open setup.

Download and install the current APK. Use Wi-Fi to download the three matching resource ZIPs automatically, or import all three using setup’s file picker.

APK & matching resources →
02

Verify and restore the resources.

Keep setup open while it verifies hashes and extracts the files. Pause and retry are supported. Allow room for the APK, 5.56 GB source resources, 9.62 GB decoded resources and temporary files.

03

Run the original game once.

Use setup to start the original game, wait for login, then close it. Return to setup and confirm the first-start attempt. If its old verification server is unavailable, follow the explicit continuation option shown in setup.

04

Apply Crows and play.

Apply Crows from setup, complete the account step and use Play after integrity verification. Existing account files are preserved during normal setup and repair.

GOOD TO KNOW

Next time, just open SMC.

Later launches check the saved resource state and open the game automatically. An update or manual repair performs a full check.

No Termux or manual Android folder copying is required.

Setup’s resource destination:

Android/data/com.netease.g93na/files/netease/smc/
Updating an existing community install requires the same signing certificate. The original NetEase-signed APK has a different certificate. Installation help →

Protect your account.

Preserving files during an update is different from recovering them after uninstall. Current r4 has no external account export/import. Read account and backup guidance →
