# SMC public distribution repository instructions

This repository owns the SMC download website, approved release artifacts, player guides, resource manifests/checksums and approved public evidence. Source, build/audit tools, development reports and workflow skills belong to private l3al3y/smc-crows-source. Portfolio is navigation and legacy resource compatibility only; never use it for new SMC work/releases.

Read REPOSITORY-LAYOUT.md before changing distribution. Publish only after explicit user authorization for the exact release. Keep private source, credentials, signing keys, account files, raw phone logs/traces and local machine paths out of public artifacts. Check both nested archives and normal files before uploads.

Preserve proven APK/resource identities, legacy installed-client URLs, freeze/resource-completeness notices and the APK request counter. A new main commit does not automatically deploy the pinned worker website. Verify anonymous byte ranges, full hashes where payloads change, MIME types, redirects and browser-visible links before switching live routes. Do not attribute historical screenshots or FPS reports to an untested APK.
